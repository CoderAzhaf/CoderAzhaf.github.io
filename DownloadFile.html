Local Download: Download all files in one zip folder when running locally

To create a zip of all files locally:

  1. Open terminal/command prompt in the project folder
  2. Run: npm install archiver
  3. Access: http://localhost:3000/api/download/all-files.zip

Or use a tool like:

  • 7-Zip, WinRAR, or Windows built-in compression
  • Clone from GitHub for the complete project
