Compatibility

This page uses old-style HTML and simple CSS so it can load on older Microsoft browsers. Some interactive tools still need a newer browser because old Internet Explorer does not support modern login storage, video calls, service workers, or the current web API features.

Very old systems may also need plain HTTP or a local network address because their browsers may not understand modern HTTPS security.
